登入身份

遊戲使用 Supabase 處理登入及雲端紀錄。使用 Google 登入時，Google 與 Supabase 會處理你授權的基本身份資料，包括帳號識別碼、電郵及基本個人資料。使用電郵驗證碼登入時，電郵地址會用於寄送一次性登入驗證碼；寄信經已設定的 Resend 服務處理。

挑戰與排行榜

雲端紀錄包括每局挑戰識別碼、難度、已完成層數、完成該層用時、總用時、擊倒數、神器、技能分支、挑戰狀態、開始時間及離線提交標記。呢啲資料用於保存歷次挑戰、合併成績同計算各難度最佳排行。

排行榜會公開玩家暱稱與識別資料、最佳層數及用時、配搭同離線提交標記。登入電郵唔會自動放入排行榜，請選擇願意公開嘅暱稱。個人完整挑戰歷史只供登入該帳號嘅玩家查閱。

本機與離線資料

瀏覽器會在本機保存訪客識別、遊戲設定、登入工作階段、歷次挑戰及待補交紀錄。首次登入時，該瀏覽器尚未綁定帳號嘅訪客成績會合併到登入帳號。已綁定嘅紀錄會繼續屬於原本帳號，避免切換帳號時混入另一位玩家嘅歷史。

離線挑戰會先保存在裝置，連網並登入原本帳號後再嘗試同步。清除瀏覽器資料或使用無痕模式，可能令未同步紀錄無法找回。本機資料清除唔會自動刪除已保存嘅雲端紀錄。

流量與遊玩統計

官網會記錄每次開啟遊戲嘅隨機到訪識別碼、日期、推廣平台分類、遊戲語言、一般挑戰開局次數及實際遊玩時間，用於比較宣傳成效。統計紀錄唔包含帳號、電郵、完整來源網址或 IP 地址，亦唔會連結到排行榜。資料可能先保存在瀏覽器，連網後補交至 Supabase。瀏覽器啟用「請勿追蹤」或 Global Privacy Control 時會跳過呢項統計。

保留、查詢與刪除

雲端紀錄會保留供個人歷史及排行榜使用。如需查詢或要求刪除帳號與雲端紀錄，請透過遊戲維護頁聯絡維護者。處理前需要核實帳號擁有權；公開留言請勿附上登入驗證碼、密碼或登入憑證。

其他服務

網站由 GitHub Pages 提供。Google、Supabase、Resend 及網站寄存服務會按各自服務政策處理提供服務所需嘅連線及操作紀錄。遊戲目前嘅登入、同步同公開內容以本頁及實際介面說明為準。

獎勵廣告

啟用廣告後，遊戲會透過 Google AdSense 檢查廣告供應。Google 可能使用 Cookie、裝置識別碼及連線資料投放、衡量廣告同防止濫用。玩家可自行選擇是否觀看廣告復活。詳情可參閱Google 點樣使用合作網站嘅資料。
