# 宣傳平台引流統計

在遊戲專案的 Supabase SQL Editor 套用 [統計遷移檔](migrations/202611230001_traffic_analytics.sql)，再執行 [最近 30 日報表](traffic-report.sql)。報表以香港日期計算，預設按到訪次數排序，也顯示有開局的到訪次數、開局率、一般挑戰開局總數及實際遊玩時間。

每次開啟遊戲頁算一次到訪。同一到訪可以玩多局。匿名訪客和已登入玩家都按同一方式計數。一般挑戰沿用遊戲計時器，練習和無敵測試不計開局或遊玩時間。離線待傳紀錄會在重新連網時補傳。數據由統計上線起計。
